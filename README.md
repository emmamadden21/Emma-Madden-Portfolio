# Emma Madden Portfolio

A responsive, static portfolio website for Emma Madden.

## Preview
Open `index.html` in a browser or serve the folder with `python3 -m http.server 8000`.

## Deploy to Netlify
Connect this GitHub repository to Netlify. No build command is needed; the publish directory is the repository root (`.`). All files must be uploaded, including `assets/`.

## Editing
The current version is a static first release. Update text in `site.js`, styles in `styles.css`, and graphics in `assets/`. A Git-based content editor is planned but **not yet configured**. GitHub changes on the production branch will trigger Netlify builds once linked.
